# PM-OS docs

Documentation is organized by purpose:

| Folder | Contents |
|---|---|
| [`guides/`](guides/) | Operator how-to. [`sop.md`](guides/sop.md) — the standard operating procedure for running PM-OS. [`testing.md`](guides/testing.md) — the central test-suite reference (what every suite/test checks). [`enhancement-quickstart.md`](guides/enhancement-quickstart.md) — step-by-step enhancement pathway. [`offline-install.md`](guides/offline-install.md) — locked-down machines, mirrors and offline zip installs. `pm-os-installation-guide-for-pms.docx` — the PM-facing install guide. |
| [`reference/`](reference/) | Canonical reference. [`pm-os-spec.md`](reference/pm-os-spec.md) — the build spec (partly aspirational; the code on `main` is the source of truth — see [`../ARCHITECTURE.md`](../ARCHITECTURE.md)). [`codebase-wiki-format.md`](reference/codebase-wiki-format.md) — proposed shareable codebase-wiki format, pending eng-lead review; not yet implemented. [`generated-doc-formats.md`](reference/generated-doc-formats.md) — the section-by-section format of every artifact PM-OS generates (00-group through stage 09). |
| [`examples/`](examples/) | Worked examples of external-design inputs: [`04-design-spec-brief-example.md`](examples/04-design-spec-brief-example.md) (a stage-04 brief), [`design-in-ia-example.yaml`](examples/design-in-ia-example.yaml) and [`design-notes-example.md`](examples/design-notes-example.md) (the designer's return). These ship in the offline zip. |
| [`roadmap/`](roadmap/) | Current state + forward planning. [`current-state-review.md`](roadmap/current-state-review.md) — the canonical state review and roadmap. [`backlog.md`](roadmap/backlog.md) — the active backlog. Open explorations (not decisions): [`product-shape-and-flexibility-brainstorm.md`](roadmap/product-shape-and-flexibility-brainstorm.md) — product-shape flexibility; [`technical-optimisation-brainstorm.md`](roadmap/technical-optimisation-brainstorm.md) — the technical/knowledge layer (Obsidian, Graphify, context routing, graph edges); [`pm-experience-brainstorm.md`](roadmap/pm-experience-brainstorm.md) — usability and the PM-facing surface. [`tech-lead-permissions-review.md`](roadmap/tech-lead-permissions-review.md) — what PM-OS needs to run and what needs approval before wider rollout. |
| [`plans/`](plans/) | Design & implementation plans (each carries its own status — implemented / in-progress / not-started). Most recently shipped: [`pm-os-external-design-authority-plan.md`](plans/pm-os-external-design-authority-plan.md) — PDLC v2, moving design authority to the designer, and [`pm-os-external-design-authority-execution-plan.md`](plans/pm-os-external-design-authority-execution-plan.md) — its productization (both shipped in v1.5.1). |
| [`archive/`](archive/) | Superseded historical documents, kept for provenance. |

Top-level docs that live at the repo root (by convention): [`../README.md`](../README.md), [`../ARCHITECTURE.md`](../ARCHITECTURE.md) (as-built architecture), [`../CHANGELOG.md`](../CHANGELOG.md), [`../AGENTS.md`](../AGENTS.md), and [`../CLAUDE.md`](../CLAUDE.md).
